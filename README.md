# Smart School Library BD (স্মার্ট স্কুল লাইব্রেরি বিডি)

একটি পূর্ণাঙ্গ অ্যান্ড্রয়েড অ্যাপ্লিকেশন (Kotlin + Jetpack Compose) যা ৫ম–১০ম শ্রেণির শিক্ষার্থীদের জন্য জাতীয় শিক্ষাক্রমের অনুমোদিত পাঠ্যবই, সহায়ক গাইড ও স্টাডি নোট পড়ার আধুনিক প্ল্যাটফর্ম।

---

## 🚀 প্রধান বৈশিষ্ট্যসমূহ (Key Features)

1. **সরাসরি লগইন ও রেজিস্ট্রেশন (Direct Launch):**
   - কোনো অনবোর্ডিং বা ওয়েলকাম স্ক্রিনের বাড়তি ধাপ ছাড়া সরাসরি লগইন ও রেজিস্ট্রেশন স্ক্রিন চালু হয়।
   - গুগল ওয়ান-ট্যাপ সাইন-ইন (Credential Manager) এবং নিরাপদ ইমেইল/পাসওয়ার্ড প্রমাণীকরণ।

2. **নতুন লোগো ও ব্র্যান্ডিং:**
   - অ্যাপের মূল একাডেমিক ক্রেস্ট লোগো ও হাই-রেজোলিউশন অ্যাডাপটিভ আইকন ইন্টিগ্রেটেড।

3. **শ্রেণিভিত্তিক পাঠ্যবই ও গাইড (Class 5–10):**
   - ৫ম, ৬ষ্ঠ, ৭ম, ৮ম, ৯ম ও ১০ম শ্রেণির অনুমোদিত মূল বই এবং অধ্যায়ভিত্তিক সহায়ক গাইড।
   - ৯ম–১০ম শ্রেণির ক্ষেত্রে বিজ্ঞান, মানবিক ও ব্যবসায় শিক্ষা বিভাগের সঠিক ফিল্টারিং।
   - বইয়ের কার্ডে আকর্ষণীয় প্রচ্ছদ এবং নাম প্রদর্শিত। কার্ডে ক্লিক করলেই সরাসরি বিল্ট-ইন নিরাপদ PDF Reader চালু হয়।

4. **সাবস্ক্রিপশন ও পেমেন্ট ব্যবস্থা:**
   - বিকাশ, রকেট ও নগদ পার্সোনাল নাম্বারের মাধ্যমে সেন্ড মানি করে ট্রানজ্যাকশন আইডি ও প্রেরক নম্বর দিয়ে বার্ষিক সাবস্ক্রিপশন রিকোয়েস্ট।
   - ব্যবহারকারীর সুরক্ষা নিশ্চিতে পেমেন্ট নম্বর সুরক্ষিত উপায়ে কপি করার সুবিধা।

5. **প্রাইভেট ও সিকিউর স্টোরেজ ইন্টিগ্রেশন:**
   - Backblaze B2 প্রাইভেট স্টোরেজ গেটওয়ে (Supabase Edge Function) ও Firebase Storage।
   - সরাসরি স্টোরেজ লিঙ্ক এক্সপোজ না করে সাইনড টোকেন ভ্যালিডেশনের মাধ্যমে নিরাপদ পিডিএফ স্ট্রিমিং।

6. **অ্যাডমিন প্যানেল (Super Admin):**
   - ডেডিকেটেড অ্যাডমিন থেকে সরাসরি ডিভাইস মেমোরি থেকে বই/গাইড পিডিএফ এবং কভার আপলোড।
   - পেন্ডিং পেমেন্ট অনুমোদন বা বাতিলকরণ ব্যবস্থা।

---

## 🛠️ সিস্টেম রিকোয়ারমেন্ট ও টেকনোলজি স্ট্যাক

- **অপারেটিং সিস্টেম:** Android 8.0 (API Level 26) বা তদূর্ধ্ব
- **ল্যাঙ্গুয়েজ:** Kotlin 2.0+
- **UI ফ্রেমওয়ার্ক:** Jetpack Compose & Material Design 3 (M3)
- **আর্কিটেকচার:** MVVM + Clean Repository Pattern + Kotlin Coroutines & StateFlow
- **ডাটাবেস ও ব্যাকএন্ড:** Firebase Authentication & Cloud Firestore
- **ক্লাউড স্টোরেজ:** Backblaze B2 Cloud Storage (Private Bucket via Supabase Gateway)

4. Gradle Sync সম্পন্ন হওয়ার পর রান বাটনে ক্লিক করে অ্যাপটি রান করুন।
